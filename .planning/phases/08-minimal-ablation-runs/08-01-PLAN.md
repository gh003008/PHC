# Plan 08-01: Minimal Ablation Runs

**Phase:** 8 - Minimal Ablation Runs
**Status:** Accepted

## Goal

Run and preserve the smallest ablation matrix needed to test whether the main
condition depends on pain observation and pain reward pressure.

## Tasks

1. Read Phase 7 verdict. If `METRICS_BLOCKED`, stop and add the required
   instrumentation before running ablations.
2. Prepare three isolated experiment directories and copied starting
   checkpoints:
   - `phc_shape_pnn_iccv_pain_v1_main`
   - `phc_shape_pnn_iccv_pain_v1_no_obs`
   - `phc_shape_pnn_iccv_pain_v1_no_reward`
3. For each condition, submit via Slurm using a verified-free GPU index and
   explicit GRES, not direct unreserved `CUDA_VISIBLE_DEVICES`.
4. Use the same core training budget as the preserved main run unless Phase 7
   recommends a smaller instrumentation probe:
   - `env.num_envs=128`
   - `learning.params.config.horizon_length=32`
   - `learning.params.config.minibatch_size=4096`
   - `no_log=True`
   - `headless=True`
5. Apply condition-specific overrides:
   - main: `env.pain.obs.enabled=True`, `env.pain.mode=reward_only`
   - no_obs: `env.pain.obs.enabled=False`,
     `env.pain.append_to_obs=False`, `env.pain.mode=reward_only`
   - no_reward: `env.pain.obs.enabled=True`, `env.pain.mode=log_only`
6. Preserve each checkpoint and log with condition, job id, date, and epoch
   suffix.
7. Extract aggregate metrics into a comparison JSON and run
   `scripts/phc_pain_v1_evaluate.py`.
8. Write `08-SUMMARY.md` with condition table, evaluator output, and next
   recommendation.

## Verification

- Each condition has a unique checkpoint path and log path.
- Slurm output confirms each job used a specific free GRES index.
- Logs show observation/network shapes appropriate to the condition:
  `963` for pain obs on and original shape for obs off.
- Evaluator output is saved and interpreted as `PASS`, `FAIL`, or `BLOCKED`.
- `git diff --check`

## Non-Goals

- Do not run left/right side-specificity until the three-condition matrix is
  reliable.
- Do not use action guard in the main evidence conditions.
- Do not claim patient-specific or clinical validation.
