# Plan 07.1-01: Log PHC-Pain-v1 Env Scalars

**Phase:** 07.1 - Pain Metric Scalar Logging Instrumentation
**Status:** Accepted

## Goal

Make required `pain_v1_*` env extras appear as train-time scalar tags so Phase 8
can be evaluated instead of wasting GPU time on unmeasurable ablations.

1. Add a common helper that extracts numeric scalar entries whose keys start
   with `pain_v1_` from env `infos`.
2. Accumulate those scalars during AMP `play_steps` and `play_steps_rnn`.
3. Store rollout-averaged scalars in the batch dictionary.
4. Promote those scalars into `train_info`.
5. Let existing `_log_train_info` write the exact keys as TensorBoard tags.
6. Verify syntax and inspect diff.
