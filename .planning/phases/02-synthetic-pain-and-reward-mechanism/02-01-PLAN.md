# Plan 02-01: Synthetic Pain And Reward Mechanism

**Phase:** 2 - Synthetic Pain And Reward Mechanism
**Status:** Accepted

## Goal

Compute a unilateral knee pain drive/state in `HumanoidImPainV1` and use it as
the reward-only cost for the main v1.0 mechanism path.

## Tasks

1. Add side-specific knee mechanism config.
2. Build knee flexion DOF lookup for left/right knees.
3. Compute torque, flexion, ROM, and work proxy components.
4. Threshold and sensitivity-weight the proxy into side-specific pain drive.
5. Accumulate active-side body-map pain state and short memory.
6. Override v1 reward computation to subtract affected-knee pain cost only.
7. Log side-specific load, drive, state, component metrics, and proxy caveat.
