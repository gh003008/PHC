# Plan 01-01: V1 Task And Pain Observation Contract

**Phase:** 1 - V1 Task And Pain Observation Contract
**Status:** Accepted

## Goal

Create a distinct v1 task and config that append body-part pain observation
state/memory without changing the existing v0 task contract.

## Tasks

1. Add `HumanoidImPainV1` in `phc/env/tasks/humanoid_im_pain.py`.
2. Override `get_obs_size()` so v1 adds pain observation dimensions before
   `BaseTask` allocates `obs_buf`.
3. Override `_compute_observations()` to append body-part pain map state/memory.
4. Add observation metadata helpers and `extras` fields for inspection.
5. Register `HumanoidImPainV1` in `phc/utils/parse_task.py`.
6. Add `phc/data/cfg/env/env_im_pain_v1.yaml` with v1 task selection and pain
   observation schema.

## Verification

- `python3 -m py_compile phc/env/tasks/humanoid_im_pain.py phc/utils/parse_task.py`
- Sanity-check `env_im_pain_v1.yaml` contains `task: HumanoidImPainV1`,
  `append_to_obs: True`, and `active_knee_side: "right"`.

## Non-Goals

- Do not implement the unilateral medial knee pain drive.
- Do not change checkpoint loading.
- Do not run training.
