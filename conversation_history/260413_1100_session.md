## 결정사항

### Motion Library 좌표계 변환 최종 수정 (h5_to_motion_lib.py)
v5 학습 실패의 근본 원인: 좌표계 변환 오류. 다음과 같이 수정 완료:

1. **Root (Pelvis) orientation**: SMPL root rotation에 upright rotation [0.5,0.5,0.5,0.5] 설정
   - AMASS 데이터는 SMPL fitting에서 자연스럽게 포함됨
   - H5 데이터는 root orientation이 없으므로 명시적으로 추가 필요
   - 이유: `* upright_inv` 파이프라인 후 root_rot = identity → Isaac Gym에서 직립

2. **Global rotation transform**: RIGHT-multiply by upright_inv (AMASS와 동일)
   - `pose_quat_global = FK_global_rot * upright_inv`
   - 이전 오류: left-multiply by upright (잘못된 방법)

3. **Root translation**: Y-up → Z-up 변환 (upright.apply(trans))
   - AMASS trans_orig는 이미 Z-up (SMPL world coordinates)
   - H5 trans는 Y-up이므로 변환 필요: [right, height, forward] → [forward, right, height]
   - 이전 오류: 변환 안 함 or 잘못된 방향

4. **Joint angle signs (모두 반전됨)**:
   - Hip: sign = -1.0 (양쪽)
   - Knee: sign = +1.0 (양쪽)
   - Ankle: sign = +1.0 (양쪽)
   - Spine/Thorax: sign = +1.0
   - L_Shoulder offset: Rz(-85°) (was +85°)
   - R_Shoulder offset: Rz(+85°) (was -85°)
   - L_Elbow: sign = -1.0 (was +1.0)
   - R_Elbow: sign = +1.0 (was -1.0)

5. **Skeleton tree**: smpl_humanoid.xml은 Y-up frame (legs in -Y, head in +Y)
   - Isaac Gym이 MJCF 로드 시 내부적으로 Y-up → Z-up 변환 수행
   - 따라서 저장된 root_rot = identity면 humanoid가 직립

### 핵심 발견: AMASS vs H5 차이점
- AMASS trans_orig: 이미 Z-up (SMPL world coordinates에서)
- AMASS root rotation: 사람의 실제 pelvis orientation 포함 (upright 포함)
- H5 데이터: root rotation 없음 (identity), trans는 Y-up
- 해결: root에 upright rotation 추가, trans를 Z-up으로 변환
