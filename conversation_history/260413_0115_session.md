### 문서 핵심 내용

#### G/R Split → Unified Policy로 변경 제안
- 기존 v09: G (Nominal Generator) + R (Residual Policy) 2-모듈 구조
- 개정안: **단일 정책 π** conditioned on (state, α, motion_context, command)
- 이유: 
  - 인간의 perturbation response는 nominal walking의 residual이 아님 (질적으로 다른 motor plan)
  - G/R 경계가 information bottleneck 생성
  - Motion library에 walking + perturbation 데이터 모두 포함하면 별도 분리 불필요

#### Stability Margin α (연속 모드 전환)
- α ∈ [0,1]: CoP margin + XCoM margin + angular momentum rate 가중합
- 기본 가중치: w₁=0.3 (CoP), w₂=0.5 (XCoM), w₃=0.2 (ang. momentum)
- α가 policy observation + reward blending + motion library retrieval 모두에 영향

#### Perturbation Response 데이터 수집 필수
- **핵심 주장**: 인간의 perturbation response는 RL 탐색만으로 학습 불가, 실측 데이터 필요
- 필요 데이터: belt perturbation (trip/slip), lateral push, sagittal push
- 각 조건 3+ 강도 × 5+ 반복 = 최소 ~45 perturbation trials
- MoCap + force plate + (optional) EMG

#### Motion Library 확장 구조
- Command (CoM velocity) + Motion Type (walk/perturb) + α_peak으로 인덱싱
- α-conditioned retrieval: 낮은 α → walking clips, 높은 α → perturbation clips

#### Reward Function
- r_t = (1-α)·r_imit + α·r_balance + λ_style·r_amp + r_power + r_ccf_bio
- 3-stage curriculum: 
  - Stage 1 (0-5K): walking only
  - Stage 2 (5K-15K): perturbation introduction
  - Stage 3 (15K-30K): full perturbation + style enforcement

#### 개인화 (Personalization)
- Subject-specific library + AMP discriminator D_S
- Population pre-training → subject fine-tuning
- 생리학적 파라미터 (체중, ROM, 반사 지연) 직접 주입

#### Robot/External Force 핸들링
- F_ext를 policy observation에 포함 (first-class input)
- 구조화된 force profile로 훈련 (joint torque, phased assist/resist, sudden onset/offset)
- CCF가 impedance 적응 메커니즘 제공
